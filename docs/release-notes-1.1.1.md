# sydtrack v1.1.1

A substantial upgrade from v1.0.1b: customizable focus profiles, more useful analytics, and stronger tracking reliability. This release supersedes v1.1.0 and includes its features plus the latest desktop fixes. Everything stays local and private on your device.

## Focus that fits your work

- **Five built-in profiles:** General, Coding, Writing, Study, and Creative. Fresh installs include all five; existing custom profiles and tags are preserved, with starter profiles added to available slots.
- Switch profiles directly from Home or Focus Tags. Create, rename, import, and export profiles, with separate Productive, Unproductive, and Ignore lists. Quick Add edits the active profile.

## Analytics you can act on

- **See why activity was classified.** Today's ten most-used apps show separate activity rows with matched keywords, so YouTube and productive browsing no longer collapse into one “mixed” entry.
- Correct individual rows as productive, unproductive, or ignored. Today's totals and hourly history update without changing unrelated activity; previously recorded ignored time remains recoverable.
- A redesigned Month view puts focus share inside a 30-day pie, with tracked time, active days, daily average, and top apps below.

## More dependable tracking

- Productive editors stay productive when project titles contain distracting keywords. Browser content can still be classified by title.
- Improved handling of sleep, lock, pauses, delayed tracking results, and hour/day changes; expanded backups and recovery for malformed local files.

## A cleaner desktop experience

- Refined Focus Tags tiles, compact profile controls, consistent scrollbars, and confirmation messages that clear automatically.
- Analytics tooltips stay visible while hovering. Collapsed sidebar spacing and the Roundup icon are corrected.
- Consistent **sydtrack** branding, Windows executable/taskbar icon fixes, and an **open sydtrack** tray action.

**Download:** `sydtrack.exe` — portable Windows x64 app, no installation or Node.js required. Quit the previous copy from the tray before launching the update.

**Notes:** Existing data is preserved. Older activity may lack keyword details; time never recorded during Ignore cannot be recovered. Corrections apply to today, not previous days or saved session logs. Passive video playback can still count as idle. The executable is unsigned.
